# 几何山景 MAX2 / Geometric Mountain MAX2

[中文](README.md)

A mountain-themed Garmin Connect IQ watch face.

- Time, date, and two weather fields
- Three configurable data fields with Chinese or English labels
- Two goal progress arcs and battery level
- Configurable sky and mountain colors
- Phone and on-watch settings, plus AMOLED always-on display

See [supported devices](SUPPORTED_DEVICES.md).

To build, install the Garmin Connect IQ SDK and Monkey C extension for VS Code, open this project, and run **Monkey C: Run Without Debugging**. Use **Monkey C: Export Project** to create an IQ package.
